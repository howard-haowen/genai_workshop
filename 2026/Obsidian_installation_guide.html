Obsidian
下載安裝與基本操作指南

Obsidian 是一款以雙向連結為核心的個人知識管理工具，讓你的碎片化筆記形成相互串聯的知識網路。

Step 01

Obsidian 是什麼？

重點：Obsidian 完全免費，筆記資料儲存在本機，無需帳號或登入，隱私性高。若需使用同步（Sync）或發布（Publish）功能，則需額外付費。
雙向連結
知識網路
類似大腦神經元的連結方式，讓筆記之間形成知識網路，激發創造力。
本地儲存
資料自主
筆記以 .md 格式儲存於電腦，資料完全由你掌控，不依賴雲端。
免費使用
無需帳號
個人基本功能完全免費，無需註冊帳號即可立即使用。
Step 02

下載與安裝 Obsidian

注意：Obsidian 目前沒有網頁版，需下載桌面或行動裝置 App 才能使用。
🍎 macOS

macOS 使用者

  1. 前往 obsidian.md 下載 macOS 版本（.dmg）
  2. 開啟 .dmg 檔，將 Obsidian 拖入「應用程式」資料夾
  3. 從「應用程式」啟動 Obsidian
  4. 在語言設定選擇「繁體中文」，點擊「建立」新儲存庫

或使用 Homebrew 安裝：brew install --cask obsidian

📱 iPhone / iPad

iPhone / iPad 使用者

  1. 開啟 App Store，搜尋「Obsidian」
  2. 點擊「取得」並完成安裝
  3. 開啟 App，選擇建立新儲存庫或開啟現有資料夾
  4. 在語言設定選擇「繁體中文」

建議搭配 iCloud Drive 同步，讓 iPhone、iPad 與 Mac 之間的筆記自動同步。

🪟 Windows

Windows 使用者

  1. 前往 obsidian.md 下載 Windows 版本（.exe）
  2. 執行安裝程式，依提示完成安裝
  3. 從桌面捷徑或開始功能表啟動 Obsidian
  4. 在語言設定選擇「繁體中文」，點擊「建立」新儲存庫

或使用 winget 安裝：winget install Obsidian.Obsidian

🤖 Android

Android 使用者

  1. 開啟 Google Play 商店，搜尋「Obsidian」
  2. 點擊「安裝」，等待下載完成
  3. 開啟 App，選擇建立新儲存庫或開啟現有資料夾
  4. 在語言設定選擇「繁體中文」

建議搭配 Google Drive 或 Dropbox 同步，讓手機與電腦筆記保持一致。

Step 03

認識 Obsidian 介面

Obsidian 介面分為 4 個主要區域：

區域 功能說明
中央編輯區撰寫筆記、建立連結、插入圖片的主要工作區
左側工具面板顯示所有筆記與資料夾，可新增筆記、排序、搜尋
最左側工具列快速切換、關聯圖、畫布、每日筆記、模板、命令面板等功能圖示
右側工具面板查看筆記的反向連結與標籤
Step 04

四大基本操作

操作 1：建立新筆記
點擊左側工具面板的「建立新檔案」即可開始撰寫。Obsidian 支援 Markdown 語法，並提供兩種編輯模式：
  • 即時預覽（預設）：輸入 Markdown 的同時即時顯示渲染結果
  • 原始碼模式：顯示純粹的 Markdown 語法原文
格式 輸入語法
標題# 標題一　## 標題二　### 標題三
粗體**粗體文字**
斜體*斜體文字*
列點- 重點一
編號列表1. 項目一
引用> 這是引用文字
連結[連結文字](https://example.com)
操作 2：建立資料夾分類筆記
  1. 點擊左側工具面板的第二個圖示（或右鍵點擊空白處），選擇「建立新資料夾」
  2. 為資料夾命名（例如：「英國文學」）
  3. 將相關筆記（如 Jane Austen、James Joyce、J. K. Rowling）拖入資料夾，集中管理同主題內容
操作 3：使用標籤分類主題
在筆記中輸入 # 即可建立標籤（例如 #gender、#bible）。 標籤建立後，可透過左側搜尋欄或右側工具面板快速找到所有相同標籤的筆記，實現跨資料夾的主題彙整。
操作 4：建立筆記雙向連結
這是 Obsidian 最核心的功能。建立方式：
  • 在筆記中連續輸入兩個方括弧 [[
  • 跳出選單後，從筆記庫中選擇要連結的筆記
  • 若連結的檔名不存在，連結顏色會較淡（淺紫色），點擊後可直接建立新筆記
建立連結後，可點擊最左側工具列的「查看關聯圖」，以視覺化方式一覽筆記間的知識網路。

選用工具

Obsidian Web Clipper
Web Clipper 是 Obsidian 官方推出的瀏覽器擴充功能，可將網頁內容快速剪貼並儲存為 Obsidian 筆記，支援 Chrome、Firefox、Safari 與 Edge。
  • 剪貼網頁內容：一鍵擷取整篇文章或選取段落，自動轉換為 Markdown 格式存入儲存庫
  • 網頁畫線標注：在瀏覽器中直接畫線 highlight，標注內容會隨筆記一起儲存
  • 指定儲存庫與資料夾：可選擇儲存目標並套用預設的 frontmatter 模板
安裝方式：前往瀏覽器擴充功能商店，搜尋「Obsidian Web Clipper」即可安裝。
啟用 Obsidian CLI
Obsidian CLI 讓你可以在命令列中操作 Obsidian，需先升級至最新版安裝程式（1.12.7 以上）並在設定中手動啟用。
  1. 前往 設定 → 一般
  2. 找到「命令列介面」並將其啟用
  3. 依照提示完成 Obsidian CLI 的註冊步驟
  4. 開啟終端機，輸入以下指令確認已正確啟用：obsidian version
若終端機顯示版本號碼，即表示 Obsidian CLI 已成功啟用。
Step 05

安裝完成確認清單

  • 已從 obsidian.md（或行動裝置商店）下載並完成安裝
  • 已將介面語言切換為「繁體中文」
  • 已成功建立第一個儲存庫（Vault）
  • 已建立至少一則新筆記並試用 Markdown 語法
  • 已嘗試使用 [[ 建立筆記間的連結
  • 已開啟「關聯圖」查看筆記連結網絡
  • （選用）已安裝 Web Clipper 瀏覽器擴充功能
  • （選用）已在設定中啟用 Obsidian CLI 並執行 obsidian version 確認
