Ollama 本機 AI 模型安裝指南

Workshop 前置準備

Ollama
本機 AI 模型安裝指南

Ollama 讓你在自己的電腦上輕鬆執行大型語言模型，無需雲端帳號、完全離線可用。本指南協助你快速完成安裝，準備好本機 AI 環境。

Step 01

什麼是 Ollama？

Ollama 是一套開源工具，讓你只需一行指令，就能在 macOS、Windows 或 Linux 上下載並執行各種主流大型語言模型（LLM），包含 Llama、Gemma、Mistral、Phi 等。所有運算都在本機完成，資料不上傳雲端。

🔒
完全隱私
所有對話與資料均在本機處理，不上傳任何伺服器，敏感內容可放心使用。
📶
離線可用
模型下載完成後完全不需要網路連線，網路不穩環境下也能正常運作。
⚡
一鍵啟動
安裝後一行指令即可下載並執行模型，無需複雜的環境配置或帳號登入。
🆓
完全免費
Ollama 本身開源免費，大多數支援的模型亦免費使用，無需訂閱費用。
🧩
豐富模型庫
支援 Llama 3、Gemma 3、Mistral、Phi、Qwen 等數百個模型，持續更新。
🔌
API 相容
提供 OpenAI 相容 REST API，可輕鬆整合至現有應用程式或開發工具。
Step 02

確認系統需求

項目 macOS Windows
作業系統版本 macOS 11 Big Sur 以上 Windows 10 / 11（64 位元）
晶片架構 Apple Silicon（M1/M2/M3/M4）或 Intel x86_64 x86_64（支援 GPU：NVIDIA / AMD）
記憶體（RAM） 最低 8 GB，建議 16 GB 以上 最低 8 GB，建議 16 GB 以上
磁碟空間 依模型而定，建議保留 20 GB 以上 依模型而定，建議保留 20 GB 以上
GPU（選用） Apple Silicon 內建 GPU 自動加速 NVIDIA（CUDA）或 AMD（ROCm）顯示卡可加速
提示：沒有 GPU 也沒問題，Ollama 可完全使用 CPU 執行，只是速度較慢。建議先以較小的模型（如 phi3:mini 或 gemma3:1b）測試。
Step 03

安裝 Ollama

Ollama 提供兩種安裝方式：命令列（Terminal）與圖形化安裝程式（Installer）。以下分別說明 macOS 與 Windows 的操作步驟。

🍎 macOS

macOS 使用者

方法一：使用圖形化安裝程式（推薦）

  1. 前往 ollama.com/download/mac 下載 Ollama.dmg
  2. 開啟下載的 .dmg 檔案
  3. 將 Ollama 拖曳到「應用程式」資料夾
  4. 從「應用程式」啟動 Ollama，選單列會出現羊駝圖示 🦙
  5. 開啟「終端機」（Terminal），輸入以下指令確認安裝成功：
    Terminal
    ollama --version

方法二：讓 AI Agent 自動安裝

適用情境：將以下 prompt 複製後貼入 AI Agent（如 IBM Bob、GitHub Copilot 等），讓 Agent 依照你的環境自動完成安裝與設定。
🤖 AI Agent Prompt — macOS 
Set up Ollama so I can build with open models.

Ollama runs open models in two ways:
- Locally, on this computer. Speed depends on the hardware. Large models are slow on a computer without a strong GPU.
Set up Ollama so I can build with open models.

Ollama runs open models in two ways:
- Locally, on this computer. Speed depends on the hardware. Large models are slow on a computer without a strong GPU.
- In Ollama's cloud. Cloud models run on Ollama's servers, so they are fast on any computer and need no download. In the CLI, a cloud model name ends in :cloud, for example gemma4:cloud. From code, apps call the API at https://ollama.com.

Before you do anything, learn Ollama from its docs:
- Read the docs index at https://docs.ollama.com/llms.txt.
- Read https://docs.ollama.com/quickstart.md, https://docs.ollama.com/cloud.md, and https://docs.ollama.com/gpu.md.
- If I want to call Ollama from code, read https://docs.ollama.com/api/introduction.md. If this project already uses the OpenAI or Anthropic SDK, also read https://docs.ollama.com/api/openai-compatibility.md or https://docs.ollama.com/api/anthropic-compatibility.md.
- For any other question, search the full docs at https://docs.ollama.com/llms-full.txt.

Then:
1. If the ollama command is not installed, install the Ollama CLI. On macOS or Linux, run: curl -fsSL https://ollama.com/install.sh | sh. On Windows, run in PowerShell: irm https://ollama.com/install.ps1 | iex.
2. Check this computer's GPU and memory against https://docs.ollama.com/gpu.md.
3. Ask me what I want to build.
4. Recommend local models, cloud models, or both for that, and tell me why. If local models would be slow on this computer, recommend cloud models. If I don't have a paid plan, start with gemma4:cloud, which the free plan includes. Most other cloud models need a paid plan or purchased credits.

Do not sign in, create an API key, or use an API key for me. If I choose cloud models, tell me to run ollama signin, or to create a key at https://ollama.com/settings/keys.
🪟 Windows

Windows 使用者

方法一：使用圖形化安裝程式（推薦）

  1. 前往 ollama.com/download/windows 下載 OllamaSetup.exe
  2. 執行下載完成的安裝程式
  3. 依照安裝精靈完成安裝：
    • 同意授權條款
    • 選擇安裝目錄（建議使用預設值）
    • 點擊「Install」開始安裝
  4. 安裝完成後，Ollama 會在背景自動執行，系統匣會出現羊駝圖示 🦙
  5. 開啟「命令提示字元」或「PowerShell」，輸入以下指令確認安裝成功：
    PowerShell / CMD
    ollama --version

方法二：讓 AI Agent 自動安裝

Step 04

下載並執行 AI 模型

說明：Ollama 安裝完成後，使用 ollama run <模型名稱> 指令即可自動下載並啟動模型。首次下載需要時間，請保持網路連線。

推薦入門模型：

模型名稱 大小 適合情境
gemma3:1b 約 815 MB 快速測試、低記憶體裝置
phi4-mini 約 2.5 GB 輕量、推理能力佳
llama3.1:8b 約 4.7 GB 高品質回應（需 16 GB RAM）
gemma4:e4b-mlx 約 2.5 GB 🍎 macOS 專屬（Apple Silicon MLX 加速，速度快）
gemma4:e4b 約 2.5 GB 通用版本（macOS / Windows / Linux）

使用指令下載並對話（以 Gemma3:1b 為例）：

Terminal / PowerShell
ollama run gemma3:1b

其他常用指令：

Terminal / PowerShell — 列出已下載的模型
ollama list
Terminal / PowerShell — 刪除模型
ollama rm gemma3:1b
Terminal / PowerShell — 查詢更多可用模型
ollama search
Step 05

第一次使用前建議確認

  • 已完成 Ollama 軟體安裝（macOS 或 Windows）
  • 在終端機執行 ollama --version 可看到版本號
  • 已下載至少一個模型（建議 gemma3:1b 或 phi4-mini）
  • 執行 ollama run <模型名稱> 後可正常與模型對話
  • 執行 ollama list 可看到已下載的模型清單
Step 06

常見問題

Q：安裝後執行 ollama 指令卻顯示「找不到指令」？
請依序確認以下項目：
  • 關閉並重新開啟終端機（Terminal / PowerShell），讓環境變數更新
  • macOS 使用者確認 /usr/local/bin/ollama 或 /usr/bin/ollama 是否存在
  • Windows 使用者確認 PATH 環境變數是否包含 Ollama 安裝路徑
  • 嘗試重新安裝 Ollama
Q：下載模型速度很慢或中斷怎麼辦？
Ollama 支援斷點續傳，重新執行相同的 ollama run 指令會繼續未完成的下載，無需重頭開始。
Q：模型回應速度很慢怎麼辦？
建議嘗試以下方式：
  • 改用更小的模型，例如 gemma3:1b 或 phi4-mini
  • 關閉其他佔用記憶體的程式
  • 確認 GPU 加速是否正常啟用（NVIDIA 需安裝 CUDA 驅動程式）
Q：Windows 上安裝後找不到 Ollama 圖示？
Ollama 在 Windows 上會以系統匣（System Tray）常駐，請查看螢幕右下角通知區域。若未出現，可在開始功能表搜尋「Ollama」並手動啟動。
