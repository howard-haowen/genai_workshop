什麼是 Agent Skill？

SKILL.md：像一張可重複使用的任務食譜

🍳 食譜

不用每次重新教，材料、步驟、注意事項與完成標準都寫好了。

🎒 工具包

可附上 scripts 與 references，需要時才被載入，不佔用主脈絡。

🔁 可搬移

換一個 agent 平台，複製 skill folder，就能重新擁有同樣的專長。

一句話：SKILL.md 讓「怎麼做」變成 AI 可以隨時取出來用的專長，而不是每次重新口述的說明。

07 / 23
兩份文件，兩種任務

AGENTS.md 說「怎麼工作」， SKILL.md 說「怎麼做這件事」

AGENTS.md

  • 描述整個專案怎麼工作
  • 資料來源、語言偏好、輸出格式與規則
  • 幾乎每次任務都會被讀取

SKILL.md

  • 描述「某一類任務」怎麼做
  • 按需載入，不必每次塞進主脈絡
  • 可附帶 scripts、references 等額外檔案

AGENTS.md 永遠都會自動載入對話脈絡；SKILL.md 根據意圖判斷，命中後才按照需求載入。

SKILL.md 內容要求

一份完整的 SKILL.md 要說清楚這幾件事

🏷️ name ＆ description

skill 的識別碼與一句話說明用途，讓 Agent 知道這個 skill 是什麼。

⏱️ 使用時機（when to use）

明確列出觸發情境，讓 Agent 判斷何時該載入這個 skill。

📥 輸入需求

執行前需要哪些資訊，避免 Agent 猜測或遺漏。

📤 輸出格式

完成後產出什麼，格式是 Markdown、JSON、檔案，還是其他形式。

🪜 操作步驟

具體流程一步一步寫清楚，讓 Agent 有明確的執行路徑。

🚧 限制與注意事項

什麼情況下不適用、有哪些邊界或風險需要留意。

13 / 23
SKILL.md 實例拆解

以 research 技能為例對照六大原則

🏷️ name ＆ description

name: research 命名直覺；描述清楚界定核心任務：「針對高可信一手來源做調查，並在 repo 中產出 Markdown 檔案」。

⏱️ 使用時機（when to use）

以 Use when... 清楚定義觸發條件：需要調研主題、查證 API 事實、或委派閱讀工作給背景 Agent 時載入。

📥 輸入需求

明確指出需要「研究問題」與「第一手資料來源（primary sources）」，包含官方文件、原始碼、規格書或第一方 API。

📤 輸出格式

規定產出為單一 Markdown 檔案，每項論點皆須「標註出處（citing each source）」，並存放至專案既有目錄。

🪜 操作步驟

精煉為 3 步標準流程：① 啟動 background agent ② 深入一手來源查證 ③ 彙整並引註寫入 Markdown 存檔。

🚧 限制與注意事項

嚴格限制「必須追溯一手權威來源，嚴禁二次轉述」；委派背景 Agent 執行以避免阻塞主要對話。

技能示範

agent-browser：讓 Agent 操作真實瀏覽器

🎮 Demo 核心運作方式

讓 Agent 像人類一樣瀏覽網頁：直接在對話中指揮 AI 打開瀏覽器、點擊按鈕、填寫查詢欄位、翻頁閱讀並擷取網頁畫面存證。

🌐 三大人文研究與日常情境

  • 數位典藏與文獻搜尋：自動檢索線上圖書館、史料庫或新聞庫，處理多頁搜尋與資料摘錄。
  • 批次查詢與表單填寫：自動查詢學術會議與展覽資訊、填寫重複性線上報名或問卷表單。
  • 研究資料截圖與存證：將參考的網頁文章、社群討論或動態資料即時截圖，保留完整研究佐證。

✨ 核心優點（Pros）

  • 能處理「動態互動」網頁：一般工具抓不到的點擊展開、彈出視窗與分頁，它都能順利操作。
  • 過程透明、結果可見：支援即時畫面截圖與狀態紀錄，清楚掌握 AI 正在查什麼、點了哪裡。
  • 用日常自然語言指揮：不需撰寫複雜程式，只要清楚描述任務步驟，AI 就能依序執行。

⚠️ 可能的缺點與限制（Cons）

  • 執行速度較慢、耗資源：需要實際打開並載入網頁畫面，速度比純文字檢索慢，也較耗效能。
  • 驗證碼與登入阻礙：遇到「我不是機器人」驗證碼（CAPTCHA）或手機雙重驗證時需人工介入。
  • 網站改版可能失效：若目標網站版面大幅調整或按鈕位置變更，操作流程可能需要重新微調。
參考來源：agent-browser (Fast browser automation CLI for AI agents) ↗

安裝 Ollama，在自己的電腦跑 AI

🎯 目標

  • 在自己的 macOS 或 Windows 電腦安裝 Ollama
  • 下載至少一個本地模型（如 gemma3:1b 或 phi4-mini）

💡 為什麼值得試試？

  • 完全離線，資料不上雲端，隱私有保障
  • 不需訂閱費，模型下載後免費無限使用
  • 可與 VS Code 搭配，在本機測試 Agent 工作流程

📋 安裝步驟概覽

  • macOS：下載 Ollama.dmg 或使用 Homebrew
  • Windows：下載 OllamaSetup.exe 或使用 winget
  • 確認安裝：ollama --version
  • 下載模型：ollama run gemma3:1b

銜接下週：skills 與 MCP

Skill 教會 Agent「怎麼做」，MCP 讓 Agent「連得到」

📘 SKILL.md：教 AI 怎麼做

  • 整理文獻
  • 製作簡報
  • 遵循特定研究方法

🔌 MCP Server：讓 AI 可以去外面拿資料、使用工具

  • 搜尋學術資料庫
  • 讀取雲端文件
  • 操作外部系統

最簡單的記憶方式：
📘 SKILL.md＝做事的方法 ／ 🔌 MCP＝使用外部工具的能力
例如：「把找到的論文整理成文獻回顧」是 SKILL；「去學術資料庫找論文」是 MCP
